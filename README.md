# Malte Baumecker — personal website

A responsive, dependency-free academic website for GitHub Pages. All content and styles are in `index.html`; no installation or build is required. It follows the warm, restrained visual direction of Florian Schager's website, with original markup and styles and no Atlas section.

## Publish on GitHub Pages

In this repository, open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select **main** and **/ (root)**, then save. The website will be available at https://malte-baumecker.github.io/ after GitHub finishes deploying it.

## Edit the content

- **About me:** find the `ABOUT` comment in `index.html` and edit the paragraphs. The initial text summarizes public research information; add your personal background or interests here.
- **Publications:** find `PUBLICATIONS` and copy a list item. Use `publication preprint` for a preprint and `publication` for a conference paper.
- **Teaching:** find `TEACHING` and copy the course article to add courses, roles, semesters, and resource links.
- **Photo:** no portrait is included. Add your own image if desired.
- **Colors and spacing:** edit the CSS in the `<style>` element. Dark mode follows the visitor's system preference.

The page works without JavaScript, external fonts, analytics, or a build system. It includes keyboard focus styling, a skip link, responsive mobile styling, and print styles.
